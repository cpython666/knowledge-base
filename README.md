# 个人知识库

本仓库用于保存已读懂、可复用的知识，而不是收藏全文或聊天记录。

## 怎么用

按「收藏 → 提炼 → 验证 → 复用」处理材料：

1. **收藏**：把文章、项目链接或待处理材料放进 `收件箱/`，先不当成结论。
2. **提炼**：用自己的话写清问题、结论、适用条件和做法，再移到对应目录。
3. **验证**：每条笔记必须标明依据，并区分「已实测 / 文档说明 / 未验证」。
4. **复用**：需要时先看适用条件与限制，再按做法执行。

新笔记请复制 [`模板/知识笔记.md`](模板/知识笔记.md)。

## 目录

- `收件箱/`：尚未提炼的材料
- `项目经验/`：实际解决问题后的原因、修法和防再犯记录
- `工具与方法/`：可重复使用的操作步骤与方法
- `决策记录/`：做过的选择、理由，以及当时未选其他方案的原因
- `模板/`：知识笔记模板

## 不要写入的内容

只存知识，不存密码、令牌、密钥、`.env`、凭据或未脱敏的私人材料。

## 验证状态

每条笔记必须明确标注以下之一，不可混写：

- **已实测**：亲身验证过，并写明验证日期
- **文档说明**：来自文档或他人陈述，尚未亲自验证
- **未验证**：尚待核实，不能当作可靠结论
